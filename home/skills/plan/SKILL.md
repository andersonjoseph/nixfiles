Understand the task, then design the change — do not make it.

## 1. Understand

Explore read-only: read files, search, run read-only commands, and
delegate to the explorer (Model roles in the personal instructions)
when that is faster. Do not create or modify any file. Stay in
planning: if the user asks to implement, point at the `implement`
skill.

## 2. Open questions

When something is unclear or undecided, load the `grilling` skill and
settle it with me, one question at a time. Skip this when the task is
already clear.

## 3. Final plan

Send the final plan to my Plannotator Inbox (`plannotator_inbox`
send_message, the plan file in `attachments`), then give it in chat: ordered steps, one bounded action each, and the
files to touch. Do not wait for thread replies; I give feedback in chat.
